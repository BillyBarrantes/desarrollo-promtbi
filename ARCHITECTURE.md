# ARCHITECTURE.md - VIPROMT

## Stack Tecnológico
- **Frontend:** Next.js 14+ (TypeScript), React, Tailwind CSS. (`/frontend`)
- **Backend:** FastAPI (Python 3.13), Uvicorn, Pytest. (`/backend`)
- **AI Engine:** Google Gemini API (`app/services/gemini_service.py`).
- **Validador Geométrico:** `app/validators/deterministic_validator.py`.

## Puertos Locales de Desarrollo
- Frontend: `http://localhost:3000`
- Backend FastAPI: `http://localhost:8000`
