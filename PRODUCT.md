# PRODUCT.md - VIPROMT (Generador de Layouts CAD/3D)

## Visión del Producto
SaaS para generación, iteración y exportación de layouts arquitectónicos y bloques CAD 2D/3D mediante lenguaje natural optimizado con Inteligencia Artificial.

## Módulos Principales
1. **Motor de Razonamiento (IA):** Generación de layouts usando Gemini API.
2. **Validador Determinista:** Motor en Python que verifica geometría y restricciones sin alucinación.
3. **Visor 2D / CAD:** Interfaz React/Next.js con Canvas/SVG para renderizado en tiempo real.
4. **Exportador DXF:** Generación de archivos planos compatibles con AutoCAD.
