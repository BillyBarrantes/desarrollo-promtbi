# RUNBOOK.md - Operaciones y Comandos

## Backend (Python / FastAPI)
- Instalar dependencias: `cd backend && pip install -r requirements.txt`
- Ejecutar servidor dev: `cd backend && uvicorn app.main:app --reload`
- Correr pruebas unitarias: `cd backend && pytest`

## Frontend (Next.js)
- Instalar dependencias: `cd frontend && npm install` (o `pnpm install`)
- Ejecutar servidor dev: `cd frontend && npm run dev`
- Correr linter: `cd frontend && npm run lint`
